게임 상세 가이드 & 아이템 도감

기존 15×15(225칸)에서 3배에 달하는 26×26(676칸)으로 대폭 넓어졌습니다. 긴 차체를 회전시키고 장애물을 회피할 충분한 여유 공간을 제공합니다.

2. 무작위 3종 아이템 시스템
일시적 속도 감소 (쿨링 브레이크)

6초 동안 이동 틱 딜레이가 늘어나 차량이 천천히 주행합니다. 고속 상황에서 꼬임 위험을 안전하게 풀어줍니다.

획득 즉시 꼬리 3칸이 깔끔하게 잘려나가며 차체가 가벼워집니다 (최소 3칸 유지). 보너스 30점 지급!

일시적 무적 (5초 지속)

정확히 5초 동안 차체에 에너지 방어막이 회전하며, 자신의 몸통 충돌 및 30초 도로 차단벽 충돌을 완전 방어하고 돌파합니다.

연료통 단계별 확장

초기 2개로 시작하여, 연료 16개 수집 후 3개, 30개 수집 후 4개가 동시 등장하여 빠른 득점과 성장이 가능합니다.

GitHub 업로드용 game 폴더 패키지

GitHub Pages에서 빌드 도구 없이 바로 실행되는 index.html, README.md, package.json 등이 모두 포함된 압축 파일입니다.

📁 바탕화면에 저장 및 GitHub 업로드 4단계 안내:
  1. 위 game.zip 버튼을 눌러 파일을 다운로드합니다.
  2. 다운로드된 game.zip 압축을 풀어 바탕화면(Desktop)의 game 폴더로 배치합니다.
  3. 바탕화면의 game 폴더 안에서 마우스 우클릭 후 '터미널 열기'(또는 Git Bash)를 실행합니다.
  4. 아래 Git 명령어를 복사하여 터미널에 붙여넣기 실행합니다.
Git 업로드 명령어 
git init
git add .
git commit -m "feat: Super Car Snake GitHub Pages release"
git branch -M main
git remote add origin https://github.com/당신의깃허브아이디/리포지토리이름.git
git push -u origin main

* 배포 후 GitHub 리포지토리의 [Settings] ➔ [Pages] ➔ Source를 "Deploy from a branch" (Branch: main, /(root))로 설정하면 1분 안에 즉시 게임 웹사이트가 열립니다!
